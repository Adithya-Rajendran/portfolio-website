# Glossary

This table gives the approved technical names and technical verbs of the project, each with its one meaning.

| Term | Kind | Forms | Meaning |
|---|---|---|---|
| agent | name | agents | A program that does a task in the repository for the owner. |
| ASD-STE100 | name | ASD, STE100 | The standard for Simplified Technical English. |
| assembly | name | assemblies | A module that gives a sequence of links to other modules, with a title and a purpose. |
| Atrium | name | - | The room at the path `/`, where a visitor starts. |
| bake | verb | bakes, baked | To calculate the light of a room in Blender and keep it in textures. |
| Blender | name | - | The program that makes the models of the rooms and bakes their light. |
| branch | name | branches | A line of commits in the repository. |
| browser | name | browsers | The program that shows the site to a visitor. |
| build | name | - | The step that makes the files of the site in `dist/`. |
| cache | name | caches | A directory that keeps a copy of data for use at a later time. |
| card | name | cards | The part of the program plan that gives one task. |
| CI | name | - | The checks that the CI host runs on a commit. |
| class | name | classes | A Python type of object, with its functions. |
| cluster | name | clusters | A group of nouns that come one after the other in a sentence. |
| comment | name | comments | Text in a source file that a program does not read as code. |
| commit | name | commits | A recorded change to the files of the repository. |
| Comms | name | - | The room at the path `/contact/`. |
| concept | name | concepts | A module that tells what a thing is and how it works. |
| container | name | containers | A set of programs and files that Docker runs apart from the other programs of the machine. |
| CSS | name | - | The language of the styles of the pages. |
| cycle | name | cycles | A path of links that comes back to its start. |
| dependency | name | dependencies | A link from one module to a module that it uses. |
| depends | name | - | The front matter key that lists the Markdown files that a module links to. |
| directive | name | directives | A comment that a tool reads as an instruction, for example `eslint-disable`. |
| Docker | name | - | The program that runs the browser checks in containers. |
| Dockerfile | name | Dockerfiles | A file that tells Docker how to make a container image. |
| docstring | name | docstrings | A string at the start of a Python module, class or function. |
| documentation | name | - | The Markdown files that tell how the product works and how to use it. |
| email | name | - | An address for messages on the internet. |
| engine | name | - | The part of the site that draws the rooms with three.js. |
| English | name | - | The language of the documentation. |
| exit | name | - | Only in "exit code": the number that a program gives when it stops. |
| Fabrication | name | - | The room at the path `/portfolio/`. |
| field | name | fields | A value with a name in an object. |
| frame | name | frames | One image in the sequence of images that the engine draws. |
| Git | name | - | The version control program of the repository. |
| GitHub | name | - | The service that keeps the public copy of the repository and its pull requests. |
| glossary | name | - | This module, the list of approved technical names and technical verbs. |
| GLSL | name | - | The language of the shaders. |
| governor | name | - | The part of the engine that changes the render quality to keep the frame time in its limit. |
| GPU | name | GPUs | The device that draws the images of the rooms. |
| graph | name | graphs | The modules and the links between them. |
| hash | name | hashes | A short value that a calculation makes from the content of a file. |
| header | name | headers | The comment on the first line of a source file that tells what the file contains. |
| heading | name | headings | A line that starts with `#` and gives the name of a section in Markdown. |
| host | name | hosts | A computer on the network, for example the CI host. |
| HTML | name | - | The language of the pages of the site. |
| idiom | name | idioms | A group of words with a meaning that is different from the meanings of its words. |
| imperative | name | - | The form of a verb that gives an instruction, for example "Run". |
| index | name | - | The assembly `docs/assembly_index.md`, where the links to all modules start. |
| internet | name | - | The public network of computers. |
| JavaScript | name | - | The language of the scripts of the site. |
| KTX2 | name | - | The file format of the textures. |
| layer | name | - | Only in "page layer": the part of the site that makes the page around the rooms. |
| legacy | name | - | A file that does not obey the rules yet, and has a line on the legacy list. |
| Library | name | - | The room at the path `/blog/`. |
| link | name | links | Text in a Markdown file that goes to a different file or heading. |
| Lounge | name | - | The room at the path `/about/`. |
| Markdown | name | - | The text format of the documentation files. |
| matter | name | - | Only in "front matter": the block of keys at the start of a module. |
| merge | verb | merges, merged | To put the commits of one branch into a different branch. |
| modular | name | - | Only in "modular documentation": documentation that has modules. |
| module | name | modules | A documentation file of one type: concept, procedure, reference or assembly. |
| Navigation | name | - | The room at the path `/experience/`. |
| network | name | networks | Computers that connect to each other. |
| noun | name | nouns | A word that is the name of a thing. |
| object | name | objects | A value in code that has fields and functions. |
| owner | name | owners | The person who has the repository and the site. |
| pack | verb | packs, packed | To make the room files for the site from the bake files with `tools/pack.py`. |
| passive | name | - | The form of a sentence, for example `is run`, where the subject does not do the action. |
| Playwright | name | - | The browser test tool that runs the browser checks. |
| post | name | posts | A text in `data/posts/` that the Library shows. |
| PowerShell | name | - | The shell language of the scripts that run on the bake machine. |
| prefix | name | prefixes | The first part of a file name, for example `proc_`. |
| prerequisite | name | prerequisites | A condition that must be true before you start a procedure. |
| procedure | name | procedures | A module that gives the steps of a task. |
| pull | name | - | Only in "pull request": a request on GitHub to merge one branch into a different branch. |
| Python | name | - | The language of the tools in `tools/` and `blender/`. |
| Red Hat | name | - | The company that published the modular documentation guide. |
| reference | name | references | A module that gives facts in tables or lists. |
| render | verb | renders | To draw an image of a scene. |
| repository | name | - | The Git copy of the files of the site, with their history. |
| room | name | rooms | One of the six areas of the station that a visitor can go to. |
| script | name | scripts | A file of code that a program runs, for example a shell script. |
| shader | name | shaders | A program that runs on the GPU and calculates the color of points. |
| shebang | name | - | The first line of a script that starts with `#!` and names its program. |
| shell | name | - | The program that reads commands and runs them, for example `bash`. |
| Simplified | name | - | Only in "Simplified Technical English", the language standard of the documentation. |
| site | name | - | The pages, scripts and files that a visitor opens in a browser. |
| slang | name | - | Words that are not standard words of the language. |
| Solid | name | - | The library that the page layer uses. |
| station | name | - | The site as one place with six rooms. |
| STE | name | - | Simplified Technical English. |
| string | name | strings | A sequence of characters in code. |
| style | name | styles | A CSS rule for the color, the size or the position of a part of a page. |
| suite | name | - | The tier that runs all browser checks with `tools/check.sh`. |
| Technical | name | - | Only in "Simplified Technical English". |
| tense | name | tenses | The form of a verb that shows the time of the action. |
| texture | name | textures | An image that gives the color or the light of a surface. |
| three.js | name | - | The library that the engine uses to draw the rooms. |
| tier | name | tiers | A set of checks with a name, for example `static`, that `ci` runs. |
| token | name | tokens | A text that gives access to a service. |
| TypeScript | name | - | The language with types that the build changes into JavaScript. |
| Vale | name | - | The tool that checks the language of the documentation. |
| verification | name | - | The last section of a procedure, which tells how to make sure that the steps have the correct result. |
| visitor | name | visitors | A person who uses the site in a browser. |
| voice | name | - | The active or passive form of a sentence. |
| WebGL | name | - | The browser function that the engine uses to draw with the GPU. |
| worktree | name | worktrees | A directory with a copy of one branch of the repository. |
