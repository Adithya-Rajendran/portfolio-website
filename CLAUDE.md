# Repository guide

The public application is Astro on Cloudflare Workers. Sanity is the editorial source, and the Studio is built separately into the static `/studio` assets. TypeScript supplies request handlers and browser enhancements; The orbital view loads Three.js automatically on the experience page; project viewers load it on activation. Preserve the HTML content and keyboard paths when JavaScript, WebGL, or motion is unavailable.

Read [the migration plan](docs/v2-rewrite-plan.md), [implementation report](docs/v2-implementation-report.md), and [README](README.md) for route contracts, current limitations, environment configuration, and deployment/rollback steps. User instructions take precedence over old Next/Vercel design assumptions. Do not mutate Sanity content or deploy its schema as part of routine code changes.

CMS reads use the published perspective, no CDN and request-time date filtering. Do not turn an upstream error into a false 404 or empty successful page, expose drafts/future posts, or add a shared cache without a documented freshness and invalidation contract. Preserve authored figures, captions, credits, galleries, code, callouts, links, footnotes, embeds, revisions, and related content in pages and feed. Unknown slugs must return 404.

Contact delivery must not publish the recipient or credentials. Validate origin, content type and bounded request size; require the rate-limit binding and server-side Turnstile verification with exact action and hostname, and report success only after Resend accepts a message. Keep the verified sender fixed by deployment configuration and use the visitor address only as Reply-To. Preserve unsent drafts and a non-JavaScript alternative. Test with injected providers, never real automated email.

Use Node 24 and the pinned pnpm version. Run `pnpm lint`, `pnpm typecheck`, `pnpm format:check`, `pnpm test`, `pnpm build`, and `pnpm test:e2e`, plus `pnpm exec wrangler deploy --dry-run` for Worker changes. The build requires public `SANITY_STUDIO_PROJECT_ID` and `SANITY_STUDIO_DATASET`; see README. Preserve the license and attribution files alongside fonts and images. Never hardcode project IDs, recipient addresses, API keys or secrets.
