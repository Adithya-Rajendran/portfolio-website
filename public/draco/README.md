# Draco JavaScript decoder

`draco_decoder.js` is the glTF-compatible decoder distributed with Three.js 0.186.1, from Google's [Draco project](https://github.com/google/draco). It is vendored unchanged. The accompanying `LICENSE` is Apache-2.0.

The experience page uses this decoder for the original compressed Moon and Mars surface models; the homepage also uses it for the optimized NASA/JPL rover. The JavaScript variant keeps the page within its existing script execution policy. It is intentionally excluded from project-source linting and formatting.
