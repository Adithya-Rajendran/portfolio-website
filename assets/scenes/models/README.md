# Rover model

`nasa-perseverance.glb` is NASA/JPL-Caltech's Mars 2020 Perseverance Rover 3D model, downloaded from [NASA 3D Resources](https://science.nasa.gov/3d-resources/mars-2020-perseverance-rover/) ([source repository](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Mars%202020%20Perseverance%20Rover)). Original file size: 4.76 MB. The scene poses the mast and replaces the material bearing agency identifiers with a neutral finish. NASA's [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) require acknowledgment and prohibit implied endorsement; agency insignia and identifiers have separate restrictions. The model is an illustrative depiction, not an indication of affiliation or endorsement.

The source model uses Draco compression; Blender decodes it during import. `scripts/artwork/prepare-home-rover.py` bakes the deployed pose from `horizon.blend`, batches the parts by material and exports the approximately 2.6 MB `public/models/home-rover-v1.glb`. The homepage loads this optimized model into its native Three.js terrain. The original authoring file remains outside the public assets.
