# The site

Arcadia Station is a portfolio site with 3D rooms.
Blender calculates the light of the rooms with a path trace, and the browser shows them with three.js.
The site is plain HTML, CSS and JavaScript modules, with no build step for JavaScript.

- [The station](con_station.md) tells the story world of the rooms.
- [The rooms](ref_rooms.md) gives the path and the source of each room.
- To make the rooms and the pages of a new checkout, [serve a new checkout](proc_prepare-checkout.md).
